## Residuals (not misattributions)

- `0x034318` (tax clamp) — `❔ inconclusive`: a tiny function whose only
  state is `PowerRecord +0x01` (a field, not an anchor in this set). The
  `0x4B`=75 clamp is byte-verified separately (`king.md` §3).
- `0x0363A2` / `0x035D9A` (immigration) — `⚠️`: the crosses-loop/threshold
  globals aren't in this anchor set; both are byte-verified in
  `IMMIGRATION_RECRUIT_FINDINGS.md` (not misattributions).
- `0x074688` (immigration recruit) — `❔`: confirmed a 9-byte boundary
  artifact (not a usable function entry).

**Net:** after correcting market (`0x9A4`→`func_0305A8`) and diplomacy
