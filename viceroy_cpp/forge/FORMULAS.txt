Every formula the sim computes. The named knobs are cfg values you can edit on the Rules tab (Load full ruleset). Entries with no knobs are fixed code logic -- the formula shape, enums, and the demotion/capture ladder are structural and not data-tunable. Expressions are transcribed from sim/*.cpp.

=== Economy - Sons of Liberty, tax, growth, building   [sim/economy.cpp] ===
  Warehouse capacity per good  (warehouse_cap)
    cap = (warehouse_lvl + 1) * warehouse_cap_base
    knobs: warehouse_cap_base
    Per-good storage cap; production over the cap spoils.
  Sons-of-Liberty percentage  (sol_pct)
    sol% = clamp( rebel_A * 100 / rebel_B , 0 .. 100 )   ; 0 when rebel_B <= 0
    knobs: (none - fixed code logic)
    Rebel sentiment as a percent of accumulated bell support (A=dividend, B=divisor).
  SoL membership divisor  (sol_update (divisor B))
    B -= B >> sol_decay_shift   (floor 1) ; then  B += sol_inflow_mult * population
    knobs: sol_decay_shift sol_inflow_mult
    1/64 exponential decay (shift 6) plus a per-colonist inflow each turn.
  SoL bell accumulator  (sol_update (dividend A))
    A += bells_this_turn - (A >> sol_decay_shift) ; clamp A to [0, B]
    knobs: sol_decay_shift
    Bells raise rebel sentiment; the same 1/64 decay pulls it back down.
  Tory penalty + expert bonus on a tile yield  (tory_expert_adjust)
    tory = (population*(100-sol%) + 50)/100 ; div = human ? (tory_divisor_base - difficulty) : tory_divisor_base  (floor 1) ; y -= tory/div ; if expert: era-good y += expert_era_bonus else y *= expert_mfg_mult ; y = max(y,0)
    knobs: tory_divisor_base expert_era_bonus expert_mfg_mult
    Loyalists (Tories) cut output; experts add a flat era bonus or multiply manufactured goods.
  Population growth on stored food  (colony_economic_step (growth))
    food_accum += food_per_turn ; if food_accum >= food_growth_threshold and population < max_population: population += 1 ; food_accum -= food_growth_threshold ; rebel_B += sol_birth_bonus
    knobs: food_growth_threshold max_population sol_birth_bonus
    A new colonist is born once stored food crosses the threshold; surplus carries over.
  Construction from hammers  (build_step)
    accumulate hammers into hammers_accum and build_bank ; when build_cost <= both, build_bank -= build_cost and the building/unit completes (surplus carried)
    knobs: (none - fixed code logic)
    build_cost is per-building/unit data (@BUILDING/@UNIT), not a global knob.

=== Market - European price drift   [sim/market.cpp] ===
  Per-good price decay from net sales  (price_drift)
    for each good: acc = price_base + SUM over 4 powers of max(trade,0) ; price_base -= acc >> price_drift_shift
    knobs: price_drift_shift
    Selling pushes a good's price down proportionally (>>8 = /256 each turn); buys (negative) ignored.

=== Combat - land resolution, demotion, capture   [sim/combat.cpp] ===
  Probability the attacker wins  (combat_odds)
    P(attacker wins) = atk_str / (atk_str + def_str)   ; 0 when total is 0
    knobs: (none - fixed code logic)
    Pure ATK/(ATK+DEF) odds -- the classic Colonization combat model.
  Attack/defense strength build-up  (resolve_land (strengths))
    atk = unit.attack (+difficulty_bonus if human attacker) ; def = unit.defense + terrain_defense + fort_bonus (+difficulty_bonus if human defender) ; clamp both >= 0 ; if fortified: def = def * fortify_def_num / fortify_def_den
    knobs: fortify_def_num fortify_def_den terrain_defense
    Terrain defense comes from the editable terrain_defense table; fortify adds +50% (3/2).
  The combat die  (resolve_land (roll))
    roll = rng(1, atk_str + def_str) ; attacker_won = (roll <= atk_str)
    knobs: (none - fixed code logic)
    A single uniform roll over the combined strength decides the fight.
  Loser demotion ladder  (demote)
    Soldiers->Colonists ; Dragoons->Soldiers ; Cont.Cavalry->Cont.Army ; Cavalry->Regulars ; Cont.Army->Colonists ; (Missionary loser of a ->Colonists step becomes Missionaries) ; anything else -> destroyed
    knobs: (none - fixed code logic)
    Fixed structural ladder (unit type ids) -- a code wall, not data.
  Units that change hands instead of dying  (is_capturable)
    capturable = loser is Colonists, Treasure, or Wagon Train  (taken intact by the winner)
    knobs: (none - fixed code logic)
    Fixed structural set -- a code wall, not data.

=== REF / the King - the Royal Expeditionary Force   [sim/ref.cpp] ===
  Starting REF size by difficulty d  (ref_start)
    regulars  = ref_regulars_scale*d  + ref_regulars_offset ; cavalry   = ref_cavalry_scale*d   + ref_cavalry_offset ; manowar   = ref_manowar_scale*d   + ref_manowar_offset ; artillery = ref_artillery_scale*d + ref_artillery_offset
    knobs: ref_regulars_scale ref_regulars_offset ref_cavalry_scale ref_cavalry_offset ref_manowar_scale ref_manowar_offset ref_artillery_scale ref_artillery_offset
    The King's army at game start scales with the difficulty level.
  Royal treasury growth per turn  (ref_accrue_rate)
    rate = ref_accrue_scale*d + ref_accrue_offset ; then for each gate year in ref_accrue_gate_years with year >= gate: rate *= 2
    knobs: ref_accrue_scale ref_accrue_offset ref_accrue_gate_years
    The King saves faster as the game advances (doubles at each gate year).
  Spending the treasury on new REF units  (ref_purchase)
    while royal_money >= ref_unit_cost: if regulars+2 > ref_cavalry_ratio*cavalry -> +1 cavalry ; else if regulars > ref_artillery_ratio*artillery -> +1 artillery ; else if (regulars+cavalry+artillery+5) > ref_naval_ratio*manowar -> +1 man-o-war ; else +1 regular ; royal_money -= ref_unit_cost
    knobs: ref_unit_cost ref_cavalry_ratio ref_artillery_ratio ref_naval_ratio
    Buys to keep target ratios of cavalry/artillery/ships to regulars.

=== Founding Fathers - recruitment cost & availability   [sim/founding_fathers.cpp] ===
  Bells (or gold) to recruit the next father  (ff_cost)
    post-independence: cost = difficulty*ff_post_indep_scale + ff_post_indep_offset ; otherwise base = human ? (difficulty+ff_human_offset)*ff_human_scale : (ff_ai_offset-difficulty)*ff_ai_scale ; for each gate in ff_gate_years with year>=gate: cost += cost >> ff_compounding_shift  (x1.5) ; cost = (ff_count+1)*cost + 1 ; if ff_count==0: cost >>= ff_first_father_shift  (half price)
    knobs: ff_post_indep_scale ff_post_indep_offset ff_human_offset ff_human_scale ff_ai_offset ff_ai_scale ff_gate_years ff_compounding_shift ff_first_father_shift
    Each father costs more than the last; later eras compound it; the first is half price.
  Era band for father weighting  (ff_era_band)
    band = (year < 1600) ? 0 : (year < 1700) ? 1 : 2
    knobs: (none - fixed code logic)
    Fixed era cutoffs (code) used to weight which fathers appear.
  Which fathers may be offered  (ff_available)
    offerable = any father not yet owned  (next pick is a weighted random over all un-owned)
    knobs: (none - fixed code logic)
    Byte-verified: no intra-category ordering gate -- simply un-acquired.

=== Immigration - religious unrest & the docks   [sim/immigration.cpp] ===
  Crosses needed for the next immigrant  (crosses_threshold)
    a = total_workers + unit_count ; if a < imm_threshold_cap: a = a*imm_sub4k_mult + imm_sub4k_offset ; cap a at imm_threshold_cap ; if AI: a = a*(imm_ai_scale - difficulty)/imm_ai_divisor ; if player 0 (England): a = a*imm_england_num/imm_england_den
    knobs: imm_threshold_cap imm_sub4k_mult imm_sub4k_offset imm_ai_scale imm_ai_divisor imm_england_num imm_england_den
    More colonists raise the bar; England immigrates faster (x2/3).
  Spawning an immigrant on the dock  (immigration_step)
    crosses_accum += crosses_gained ; if crosses_accum > threshold: spawn a Free Colonist at dock slot rng(0, imm_dock_slots-1) ; crosses_accum = 0
    knobs: imm_dock_slots
    When accumulated crosses pass the threshold, a recruit appears in a random dock slot.

=== Turn loop - phase order & calendar   [sim/game.cpp, sim/turn.cpp] ===
  Order of operations each turn  (step_turn)
    1) production: every colony runs colony_economic_step ; 2) market: price_drift once ; 3) immigration: each of 4 powers, crosses = imm_base_crosses + SUM of its colonies' crosses_output ; 4) REF: human player's royal_money += accrue rate, then ref_purchase ; 5) units: refresh_moves then apply_orders (all owners) ; 6) advance_cadence
    knobs: imm_base_crosses
    Fixed phase sequence; only the base-crosses scalar is a knob.
  Calendar advance  (advance_cadence)
    turn += 1 ; if year < 1600: year += 1  (1 turn = 1 year) ; else season = (season+1) mod 2, and year += 1 when season wraps to 0  (2 seasons/year)
    knobs: (none - fixed code logic)
    Fixed calendar: yearly turns before 1600, two seasons per year after.

=== Units & movement - orders, routing, terrain cost   [sim/unit_turn.cpp] ===
  Move points restored each turn  (refresh_moves)
    moves_left = unit.movement   (per unit type)
    knobs: (none - fixed code logic)
    Movement allowance is per-unit data (@UNIT movement column).
  Executing a move order  (apply_orders (GOTO))
    greedy step = sign(target - pos) on each axis ; if that tile is off-map or wrong land/water -> find_step routes around it ; enemy occupant -> combat ; friendly -> blocked ; entering a tile costs terrain_move[id] (floor 1), but a unit always moves at least one tile
    knobs: terrain_move
    Greedy stepping with Dijkstra fallback; entry cost comes from the editable terrain_move table.
  Obstacle-routing pathfinder  (find_step)
    Dijkstra over passable tiles (passable = naval flag matches Ocean/Sea-Lane), 8-connected, edge cost = terrain_move[id] ; returns the first step of the least-cost route, or none
    knobs: terrain_move
    Routes a unit around coastlines/obstacles toward its target.
  Combat triggered by a move  (do_combat)
    attacker vs the occupant (defender fortified if its order is FORTIFY) ; loser is captured, destroyed, or demoted in place ; attacking sets attacker moves_left = 0
    knobs: (none - fixed code logic)
    Wraps resolve_land for unit-vs-unit encounters during movement.

=== Natives - missions, tension, trade, tribute   [sim/natives.cpp] ===
  Mission conversion chance  (mission_threshold / converts / prob)
    threshold = tribe_level + 2 ; if Jesuit: threshold *= 2 ; converts when rng(0..15) < threshold ; probability = threshold / 15
    knobs: (none - fixed code logic)
    Code-side native formulas (literals; not in the cfg block).
  Native tension update  (apply_tension)
    if delta>0: halve if a French power, halve again if Pocahontas ; tension = clamp(tension + delta, 0 .. 100)
    knobs: (none - fixed code logic)
    French diplomacy and the Pocahontas father each soften provocations.
  Native trade price percent  (native_trade_price)
    p = max(5*difficulty + 50, 2*tax_pct) ; cap p at 90
    knobs: (none - fixed code logic)
    Code-side; rises with difficulty and your tax rate, capped at 90%.
  Gold a native demand resolves to  (tribute_gold)
    hi = min(3*settlement_wealth + 10, 100) ; gold = clamp(demand, 10 .. hi)
    knobs: (none - fixed code logic)
    Code-side bounds on a tribute demand.

=== Diplomacy - war/peace/treaty & AI nerve   [sim/diplomacy.cpp] ===
  Relationship state transitions  (declare_war / make_peace / sign_treaty)
    war/peace toggle the AT_WAR and WAR relation bits both ways ; sign_treaty sets the TREATY bit, makes peace, and sets a cooldown = treaty_cooldown(turn)
    knobs: (none - fixed code logic)
    Bit-flag relationship bookkeeping between the 4 powers.
  Whether an AI follows through on a demand  (ai_acts)
    restrained = (attitude >> 2 > demand_score) and (demand_score > 12) and (rng(0,4) != 0) ; the AI acts = not restrained
    knobs: (none - fixed code logic)
    Code-side nerve check: a calm, cautious AI sometimes backs down.
