⏱ What triggers the “War of the Spanish Succession” message — and when

What it does: it is a single-player-only European political event. When it fires, the game ranks the four European crowns by a weighted strength score and the strongest crown annexes the weakest crown’s entire New World colony holdings (the “Treaty of Utrecht”), then shows the message naming who lost their colonies to whom.

Pre-conditions (verified): (1) the game is not in multiplayer mode — the auto-event is disabled when two or more human players are present; (2) two or more European powers exist to compare. Once the handler runs, it performs the annexation unconditionally (no internal dice / year check) — so the timing is decided entirely by its dispatcher, the per-turn European-politics update.

How it is dispatched (traced via the thunk cross-reference): the succession handler is dispatch-only — nothing calls it by name. It is shown by the master report/event dispatcher func_0235D6 (a 27-case switch keyed on an event id 0–26) that the end-of-turn processing invokes. Each case is gated on event-pending flags and game-state counters (multiplayer flag, rebel-sentiment %, unit count…) and then calls the page-06 European handlers through the overlay thunk table.

Honest limit on “exact turn”: what remains unresolved is only the last hop — the end-of-turn code that enqueues the succession’s event id (its precise schedule / probability). The reseg function boundaries in this European-events page are mis-segmented, so isolating that one enqueue site needs a control-flow rebuild of the page. Everything else above is byte-verified.

⚠️ Other mechanics with the same tracing issue

The succession is not special — the whole War-of-Independence & King event cluster is dispatch-only (handlers reached through the European-events overlay, never called by name in the overlay code). Confirmed for: Spanish Succession, Ship Seizure, Land Capture, REF Invasion, Tory Uprising, Foreign Intervention, Foreign General joins, Mobilize Continentals, Declaration of Independence, Mercenary Offer, King REF Build-up, Tory Sentiment Rise, King Tax Raise, King Concedes. Any “exact firing turn” question about these has the same answer shape as the succession.

2 · The Revolution storyline (event flow)

The independence arc is driven by rebel sentiment (Sons of Liberty support %), not by the Spanish Succession. The two only share the single-vs-multiplayer switch.

Methodology & honesty. Every event below was located by its GAME.TXT message key, then traced to its emitting function in the re-segmented overlay disassembly and spot-checked against raw VICEROY.EXE bytes. Plain-English roles come from the message text + the verified state the function reads/writes. Where a function’s internal detail was not fully byte-verified, the card says so (“handler identified; effect from message”). The function ids (func_XXXXXX) are kept only as stable identifiers; all behavioural labels are address-free. The exact per-turn dispatch of the dispatch-only cluster is the one open item (see the notes above).
